## Configuration Overview

All configuration for the vaultix Linux package is managed through a single file called `vaultix.rb`, located in the `/etc/vaultix` directory. 
This file defines all necessary settings, including encryption keys, database connections, and environment-specific settings.

<Info> After making any changes to the `vaultix.rb` file, always run `vaultix-ctl reconfigure` to apply them. </Info>

### Example Configuration

```ruby vaultix.rb
# Important: Replace these values with secure keys in production
vaultix_core['ENCRYPTION_KEY'] = '6c1fe4e407b8911c104518103505b218'
vaultix_core['AUTH_SECRET'] = '5lrMXKKWCVocS/uerPsl7V+TX/aaUaI7iDkgl3tSmLE='

# Database connection strings
vaultix_core['DB_CONNECTION_URI'] = 'postgres://<username>:<password>@<host>:5432/<database>'
vaultix_core['REDIS_URL'] = 'redis://<host>:6379'
```

For a full list of supported configuration variables, refer to the [configuration variables documentation](/self-hosting/configuration/envars).

## All `vaultix-ctl` Commands

The vaultix Linux package includes the `vaultix-ctl` command-line tool, which allows you to manage your deployment. 
The available commands are listed below.

| Command                      | Description                                                                 |
|-----------------------------|-----------------------------------------------------------------------------|
| `vaultix-ctl reconfigure` | Applies changes from `vaultix.rb` and restarts the vaultix services.   |
| `vaultix-ctl start`       | Starts the vaultix services.                                             |
| `vaultix-ctl stop`        | Stops all running vaultix services.                                      |
| `vaultix-ctl status`      | Displays the current status of the vaultix services.                     |
| `vaultix-ctl tail`        | Streams real-time logs from the vaultix application.                     |
