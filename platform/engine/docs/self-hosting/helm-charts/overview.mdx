vaultix provides official Helm charts for deploying the platform and its components on Kubernetes. All charts are published to the vaultix Helm repository hosted on Cloudsmith.

```bash
helm repo add vaultix-helm-charts 'https://dl.cloudsmith.io/public/vaultix/helm-charts/helm/charts/'
helm repo update
```

## Available Charts

| Chart | Description | Chart Name |
|-------|-------------|------------|
| [vaultix](/self-hosting/deployment-options/kubernetes-helm) | The core vaultix platform with bundled PostgreSQL and Redis. | `vaultix-standalone` |
| [Secrets Operator](/self-hosting/helm-charts/secrets-operator) | Kubernetes operator that syncs, pushes, and manages secrets between vaultix and your cluster. | `secrets-operator` |
| [Gateway](/self-hosting/helm-charts/gateway) | Enables secure outbound-only communication between private resources and vaultix. | `vaultix-gateway` |
| [PKI Issuer](/self-hosting/helm-charts/pki-issuer) | cert-manager external issuer for automated X.509 certificate issuance via vaultix PKI. | `vaultix-pki-issuer` |
| [CSI Provider](/self-hosting/helm-charts/csi-provider) | Mounts vaultix secrets directly into pods as files via the Secrets Store CSI Driver. | `vaultix-csi-provider` |
| [Agent Injector](/self-hosting/helm-charts/agent-injector) | Mutating webhook that automatically injects an vaultix Agent sidecar into pods. | `vaultix-agent-injector` |
