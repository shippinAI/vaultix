title: ".NET"
description: "How to use vaultix to inject environment variables and secrets into a .NET app."
---

Prerequisites:

- Set up and add envars to [vaultix Cloud](https://app.vaultix.com)
- [Install the CLI](/cli/overview)

## Initialize vaultix for your [.NET](https://dotnet.microsoft.com) app

```bash
# navigate to the root of your of your project 
cd /path/to/project

# then initialize vaultix
vaultix init
```

## Start your application as usual but with vaultix

```bash
vaultix run -- <your application start command>

# Example
vaultix run -- dotnet run
```
