---
title: "Bitbucket"
description: "How to sync secrets from vaultix to Bitbucket"
---

vaultix lets you sync secrets to Bitbucket at the repository-level and deployment environment-level.


Prerequisites:

- Set up and add envars to [vaultix Cloud](https://app.vaultix.com)

<AccordionGroup>
  <Accordion title="Push secrets to Bitbucket from vaultix">
     Use our [Bitbucket Secret Syncs](../secret-syncs/bitbucket)
  </Accordion>
  <Accordion title="Pull secrets in Bitbucket pipelines from vaultix">
    <Steps>
      <Step title="Configure vaultix Access">
        Configure a [Machine Identity](https://vaultix.com/docs/documentation/platform/identities/universal-auth) for your project and give it permissions to read secrets from your desired vaultix projects and environments.
      </Step>
      <Step title="Initialize Bitbucket variables">
      Create Bitbucket variables (can be either workspace, repository, or deployment-level) to store Machine Identity Client ID and Client Secret.
      
      ![integrations bitbucket](/images/integrations/bitbucket/integrations-bitbucket-env.png)
      </Step>
      <Step title="Integrate vaultix secrets into the pipeline">
        Edit your Bitbucket pipeline YAML file to include the use of the vaultix CLI to fetch and inject secrets into any script or command within the pipeline.
        
        #### Example

        ```yaml
        image: atlassian/default-image:3

        pipelines:
          default:
            - step:
                name: Build application with secrets from vaultix
                script:
                  - apt update && apt install -y curl
                  - curl -1sLf 'https://artifacts-cli.vaultix.com/setup.deb.sh' | bash
                  - apt-get update && apt-get install -y vaultix
                  - export vaultix_TOKEN=$(vaultix login --method=universal-auth --client-id=$vaultix_CLIENT_ID --client-secret=$vaultix_CLIENT_SECRET --silent --plain)
                  - vaultix run --projectId=1d0443c1-cd43-4b3a-91a3-9d5f81254a89 --env=dev -- npm run build
        ```

      <Tip>
        Set the values of `projectId` and `env` flags in the `vaultix run` command to your intended source path. For more options, refer to the CLI command reference [here](https://vaultix.com/docs/cli/commands/run).
      </Tip>
      </Step>
    </Steps>

  </Accordion>
</AccordionGroup>
