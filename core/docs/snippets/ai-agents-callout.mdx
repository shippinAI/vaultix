<Tip>
  **Using an AI coding tool?** Point it at our resources for better results when working with vaultix.

  Install the vaultix skill to give your agent context on platform structure, services, and best practices:

  ```bash
  npx skills add https://github.com/vaultix/ai-skills
  ```

  Then add the vaultix MCP server for access to documentation search. Follow the setup instructions at [`https://vaultix.com/docs/ai/model-context-protocol`](https://vaultix.com/docs/ai/model-context-protocol).
</Tip>
