---
title: "PM2"
description: "How to use vaultix to inject environment variables and secrets with PM2 into a Node.js app"
---

Prerequisites:

- Set up and add envars to [vaultix Cloud](https://app.vaultix.com)
- [Install the CLI](/cli/overview)

## Initialize vaultix for your Node.js app

```bash
# navigate to the root of your of your project
cd /path/to/project

# then initialize vaultix
vaultix init
```

## Create a bash or js script

<CodeGroup>

```bash vaultix-run.sh
vaultix run -- npm start
```

```js vaultix-run.js
const spawn = require("child_process").spawn;

const vaultix = spawn("vaultix", ["run", "--", "npm", "start"]);

vaultix.stdout.on("data", (data) => console.log(`${data}`));
vaultix.stderr.on("data", (data) => console.error(`${data}`));
```

</CodeGroup>

## Start your application as usual but with the script

<CodeGroup>

```bash vaultix-run.sh
pm2 start vaultix-run.sh
```

```bash vaultix-run.js
pm2 start vaultix-run.js
```

</CodeGroup>
