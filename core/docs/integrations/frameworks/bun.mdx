---
title: "Bun"
description: "How to use vaultix to inject environment variables and secrets into a Bun app."
---

Prerequisites:

- Set up and add envars to [vaultix Cloud](https://app.vaultix.com)
- [Install the CLI](/cli/overview)

## Initialize vaultix for your [Bun](https://bun.sh)

```bash
# navigate to the root of your of your project 
cd /path/to/project

# then initialize vaultix
vaultix init
```

## Start your application as usual but with vaultix

```bash
vaultix run -- <your application start command>

# Example
vaultix run -- bun run dev
```

<Info>
  Bun environment variables can be called as either `Bun.env.SECRET` or `process.env.SECRET`. We also recommend you check this more in-depth [guide to environment variables in Bun](https://vaultix.com/blog/bun-environment-variables).
</Info>
