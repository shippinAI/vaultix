title: "Express, Fastify, Koa"
description: "How to use vaultix to inject environment variables and secrets into an Express app."
---

Prerequisites:

- Set up and add envars to [vaultix Cloud](https://app.vaultix.com)
- [Install the CLI](/cli/overview)

The steps apply to the following non-exhaustive list of frameworks:

- [Express](https://expressjs.com)
- [Fastify](https://www.fastify.io)
- [Koa](https://koajs.com)

## Initialize vaultix for your app

```bash
# navigate to the root of your of your project 
cd /path/to/project

# then initialize vaultix
vaultix init
```

## Start your application as usual but with vaultix

```bash
vaultix run -- <your application start command>

# Example
vaultix run -- npm run dev
```
