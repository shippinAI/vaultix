---
title: "Next.js"
description: "How to use vaultix to inject environment variables and secrets into a Next.js app."
---

Prerequisites:

- Set up and add envars to [vaultix Cloud](https://app.vaultix.com)
- [Install the CLI](/cli/overview)

## Initialize vaultix for your [Next.js](https://nextjs.org) app

```bash
# navigate to the root of your of your project 
cd /path/to/project

# then initialize vaultix
vaultix init
```

## Start your application as usual but with vaultix

```bash
vaultix run -- <your application start command>

# Example
vaultix run -- npm run dev
```

<Note>
  Note that for environment variables to be exposed to the client, you'll have
  to prefix them with `NEXT_PUBLIC_`. Read more about that
  [here](https://nextjs.org/docs/basic-features/environment-variables).
</Note>
