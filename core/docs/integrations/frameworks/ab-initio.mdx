title: "AB Initio"
description: "How to use vaultix secrets in AB Initio."
---

## Prerequisites

- Set up and add envars to [vaultix](https://app.vaultix.com).
- Install the [vaultix CLI](https://vaultix.com/docs/cli/overview) to your server.

## Setup

<Steps>
    <Step title="Authorize vaultix for AB Initio">
        Create a [machine identity](https://vaultix.com/docs/documentation/platform/identities/machine-identities#machine-identities) in vaultix and give it the appropriate read permissions for the desired project and secret paths.
    </Step>
    <Step title="Add vaultix CLI to your workflow">
        Update your AB Initio workflows to use vaultix CLI to inject vaultix secrets as environment variables.
    
        ```bash
        # Login using the machine identity. Modify this accordingly based on the authentication method used.
        export vaultix_TOKEN=$(vaultix login --method=universal-auth --client-id=$vaultix_CLIENT_ID --client-secret=$vaultix_CLIENT_SECRET --silent --plain)

        # Fetch secrets from vaultix
        vaultix export --projectId="<>" --env="prod" > vaultix.env

        # Inject secrets as environment variables
        source vaultix.env
        ```
    </Step>

</Steps>
