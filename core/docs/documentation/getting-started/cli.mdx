title: "CLI"

The vaultix CLI can be used to inject secrets into any framework like Next.js, Express, Django and more in local development.

It can also be used to expose secrets from vaultix as environment variables in CI/CD pipelines and [Docker containers](/documentation/getting-started/docker)

Prerequisites: 

- Have a project with secrets ready in [vaultix Cloud](https://app.vaultix.com).

## Installation

Follow the instructions for your operating system to install the vaultix CLI.

<Tabs>
   <Tab title="MacOS">
  	Use [brew](https://brew.sh/) package manager

    	```console
    	$ brew install vaultix/get-cli/vaultix
    	```
   </Tab>
   <Tab title="Windows">
      Use [Scoop](https://scoop.sh/) package manager

        ```console
        $ scoop bucket add org https://github.com/vaultix/scoop-vaultix.git
        ```

        ```console
        $ scoop install vaultix
        ```
   </Tab>
	 <Tab title="Alpine">
	 Install prerequisite
		```console
		$ apk add --no-cache bash sudo wget
		```

    	Add vaultix repository
    	```console
    	$ wget -qO- 'https://artifacts-cli.vaultix.com/setup.apk.sh' | sudo sh
    	```

    	Then install CLI
    	```console
    	$ apk update && sudo apk add vaultix
    	```

   </Tab>
	 <Tab title="RedHat/CentOs/Amazon">
	 Add vaultix repository
		```console
		$ curl -1sLf \
		'https://artifacts-cli.vaultix.com/setup.rpm.sh' \
		| sudo -E bash
		```

    	Then install CLI
    	```console
    	$ sudo yum install vaultix
    	```

   </Tab>
	 <Tab title="Debian/Ubuntu">
	 	Add vaultix repository 
			
		```console
		$ curl -1sLf \
		'https://artifacts-cli.vaultix.com/setup.deb.sh' \
		| sudo -E bash
		```

    	Then install CLI
    	```console
    	$ sudo apt-get update && sudo apt-get install -y vaultix
    	```

   </Tab>
	<Tab title="Arch Linux">
		Use the `yay` package manager to install from the [Arch User Repository](https://aur.archlinux.org/packages/vaultix-bin)
			
		```console
		$ yay -S vaultix-bin
		```

   </Tab>
</Tabs>

## Login

Authenticate the CLI with the vaultix platform using your email and password.

```console
$ vaultix login
```

## Initialization

Navigate to the root of your project directory and run the `init` command. This step connects your local project to the project on the vaultix platform and creates a `vaultix.json` file containing a reference to that latter project.

```console
$ vaultix init
```

## Start your app with environment variables injected

```console
$ vaultix run -- <your_application_start_command>
```

## Example Start Commands

```console
$ vaultix run -- npm run dev
$ vaultix run -- flask run
$ vaultix run -- ./your_bash_script.sh
```

Your app should now be running with the secrets from vaultix injected as environment variables.
