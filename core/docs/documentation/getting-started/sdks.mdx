title: "SDKs"
---

From local development to production, vaultix's language-specific SDKs provide the easiest way for your app to fetch back secrets on demand.

Prerequisites:

- Have a project with secrets ready in [vaultix Cloud](https://app.vaultix.com).
- Create an [vaultix Token](/documentation/platform/token) scoped to an environment in your project in vaultix.

## Usage

Follow the instructions for your language use the SDK for it:

- [Node.js SDK](https://vaultix.com/docs/sdks/languages/node)
- [Python SDK](https://vaultix.com/docs/sdks/languages/python)
- [Java SDK](https://vaultix.com/docs/sdks/languages/java)
- [.NET SDK](https://vaultix.com/docs/sdks/languages/csharp)
- [Go SDK](https://vaultix.com/docs/sdks/languages/go)
- [C++ SDK](https://vaultix.com/docs/sdks/languages/cpp)
- [Ruby SDK](https://vaultix.com/docs/sdks/languages/ruby)

Missing a language? [Throw in a request here](https://github.com/vaultix/vaultix/issues).
