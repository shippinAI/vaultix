  **Action required for Linux users.** The vaultix CLI Linux package repository has moved from Cloudsmith to `artifacts-cli.vaultix.com`. The Cloudsmith repository stops serving on **September 16, 2026**. Machines still pointed at the old URL will fail to install or update. See the [migration guide](/cli/cloudsmith-migration) for step-by-step instructions.

The vaultix CLI is a powerful command line tool that can be used to retrieve, modify, export and inject secrets into any process or application as environment variables.
You can use it across various environments, whether it's local development, CI/CD, staging, or production.

## Installation

<Tabs>
  <Tab title="MacOS">
  	Use [brew](https://brew.sh/) package manager

    	```bash
    	brew install vaultix/get-cli/vaultix
    	```

    	### Updates

    	```bash
    	brew update && brew upgrade vaultix
    	```
  </Tab>
  <Tab title="Windows">

	<Accordion title="Scoop package manager">
		Use [Scoop](https://scoop.sh/) package manager

		```bash
		scoop bucket add org https://github.com/vaultix/scoop-vaultix.git
		```

			```bash
			scoop install vaultix
			```

		### Updates

		```bash
		scoop update vaultix
		```
	</Accordion>

	<Accordion title="Winget package manager">
		Use [Winget](https://learn.microsoft.com/en-us/windows/package-manager/winget/) package manager

		```bash
		winget install vaultix
		```
	</Accordion>

  </Tab>
  <Tab title="NPM">
      Use [NPM](https://www.npmjs.com/) package manager

    	```bash
      npm install -g @vaultix/cli
    	```

    	### Updates

    	```bash
    	npm update -g @vaultix/cli
    	```
  </Tab>
	 <Tab title="Alpine">
	 Install prerequisite
		```bash
		apk add --no-cache bash sudo wget
		```

    	Add vaultix repository
    	```bash
    	wget -qO- 'https://artifacts-cli.vaultix.com/setup.apk.sh' | sudo sh
    	```

    	Then install CLI
    	```bash
    	apk update && sudo apk add vaultix
    	```
		###
		<Tip>
			If you are installing the CLI in production environments, we highly recommend to set the version of the CLI to a specific version. This will help keep your CLI version consistent across reinstalls. [View versions](https://github.com/vaultix/cli/releases)
		</Tip>
   </Tab>
	 <Tab title="RedHat/CentOs/Amazon">
	 Add vaultix repository
		```bash
		curl -1sLf \
		'https://artifacts-cli.vaultix.com/setup.rpm.sh' \
		| sudo -E bash
		```

    	Then install CLI
    	```bash
    	sudo yum install vaultix
    	```
		###
		<Tip>
			If you are installing the CLI in production environments, we highly recommend to set the version of the CLI to a specific version. This will help keep your CLI version consistent across reinstalls. [View versions](https://github.com/vaultix/cli/releases)
		</Tip>
   </Tab>
	 <Tab title="Debian/Ubuntu">

	 	Add vaultix repository 
			
		```bash
		curl -1sLf \
		'https://artifacts-cli.vaultix.com/setup.deb.sh' \
		| sudo -E bash
		```

    	Then install CLI
    	```bash
    	sudo apt-get update && sudo apt-get install -y vaultix
    	```
	###
	<Tip>
		If you are installing the CLI in production environments, we highly recommend to set the version of the CLI to a specific version. This will help keep your CLI version consistent across reinstalls. [View versions](https://github.com/vaultix/cli/releases)
	</Tip>
   </Tab>
	<Tab title="Arch Linux">
		Use the `yay` package manager to install from the [Arch User Repository](https://aur.archlinux.org/packages/vaultix-bin)
			
		```bash
		yay -S vaultix-bin
		```

	###
	<Tip>
		If you are installing the CLI in production environments, we highly recommend to set the version of the CLI to a specific version. This will help keep your CLI version consistent across reinstalls. [View versions](https://github.com/vaultix/cli/releases)
	</Tip>
   </Tab>
</Tabs>
