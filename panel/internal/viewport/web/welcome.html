Name the app.

One box for every key this app will ever need. Then put one key in dev, and run it.

  1. Name the app.

    A short name is enough. Vaultix makes one project.

  2. Put a key.

    One name, one value, the dev config. The value is not shown again on this page.

  3. Run it.

    The value is in the child process. It is not printed here.

    vaultix run --config dev -- npm run dev

dev is the config you start with. A later config can inherit it, so you change a key once.
